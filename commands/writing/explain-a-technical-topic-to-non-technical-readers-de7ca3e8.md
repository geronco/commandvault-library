Explain {{topic}} to {{audience}}.

- Start with why they should care, in one sentence.
- Use one everyday analogy and say where the analogy breaks down.
- Define any term you can't avoid, the first time you use it.
- Max {{length}} words.
- End with the one thing they should remember.
